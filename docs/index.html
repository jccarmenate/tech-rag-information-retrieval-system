Tech RAG Information Retrieval System

An Information Retrieval system with RAG for the technology/software domain — searches and synthesizes current technical information from GitHub, Hacker News, Stack Overflow, Dev.to, and arXiv, and answers questions with cited, retrieved sources.

Personal portfolio project: acquisition, indexing, retrieval, RAG, ranking, UI, web search, expansion/feedback, multimodal, and recommendation are each implemented from first principles.

Query pipeline

Modules

01

Data acquisition

5 API connectors (GitHub, HN, Dev.to, StackExchange, arXiv) + periodic refresh via APScheduler.

02

Indexing

Custom inverted index + TF-IDF, built from scratch.

03

Inference network retriever

Bayesian Inference Network (Turtle & Croft, 1991), noisy-OR over document→term→query nodes.

04

Vector database

Persistent ChromaDB, sentence-transformer embeddings, chunked so long docs aren't truncated.

05

RAG

Fuses both retrievers, generates a cited answer, swappable LLM provider (Ollama / Anthropic).

06

Ranking

Fuses relevance, recency, source authority, and aggregated feedback.

07

UI

React + TypeScript SPA — rank badges, cited-answer panel, filters.

08

Web search fallback

Insufficiency detection (volume/quality/coverage) → DuckDuckGo, results indexed for future queries.

09

Expansion & feedback

Rocchio pseudo-relevance + WordNet synonyms; 👍/👎 feedback loops back into ranking.

10

Multimodal

Images embedded with CLIP in a separate Chroma collection — text→image search.

11

Recommendation

Hybrid content-based (embedding profile) + collaborative (co-visitation).

12

Evaluation

Precision@k, Recall@k, MAP, MRR, nDCG against frozen qrels, plus RAG faithfulness (LLM-as-judge).
